# 简介

🌐 [Italiano](../01-introduzione.md) · [English](../en/01-introduzione.md) · **中文**

> ⚠️ 本页为机器翻译草稿，正式发布前需母语者校对。

这个工具源自我用来记 Nmap 命令的一堆 shell 脚本：主机发现、端口扫描、版本识别、NSE 脚本。它们本质上是可执行的笔记。能用，但有个缺陷：文件开头的变量只要写错一个，扫描就会打到毫不相干的目标上。

`nmap-cli` 消除了这个缺陷。作用域变成一个文件，包含名称、授权人签名和有效期。目标在命令行中指定，在程序去 `PATH` 里查找 Nmap 之前，就先与该文件进行比对。

## 三个设计决策

**dry-run 是默认行为。** 不加 `--esegui`，程序只打印命令并记录下来。让它误跑起来，比让它根本跑不起来更难。

**有疑问就拒绝。** 格式异常的目标、多出一位的 CIDR、解析到被排除地址的主机名：一律拒绝。误拒的代价是改一行作用域；误放的代价是一起事故。

**零依赖。** 只用 Python 标准库。一个必须对自己执行的内容负责的工具，不应该拖着五十个需要信任的包。

## 仓库里有什么

```
nmap-cli/
├── src/nmapcli/
│   ├── scope.py      加载作用域，判定目标是否允许
│   ├── profiles.py   配置与被禁标志过滤
│   ├── runner.py     构造并执行命令（从不经过 shell）
│   ├── audit.py      基于哈希链的审计日志
│   ├── firma.py      用 SSH 密钥签名和验证作用域
│   ├── rapporto.py   读取 Nmap 的 XML，生成并对比报告
│   └── cli.py        参数、提示信息、退出码
├── tests/            unittest，不需要网络，也不需要 nmap
├── docs/             本文档
├── examples/         作用域示例
├── scripts/          最初的 shell 速查脚本，项目由此而来
└── lab/              Docker 实验环境，内含故意留有漏洞的靶机
```

## 适合谁

受委托做安全测试、希望清楚留下“运行了什么、何时运行、依据哪份授权”记录的人。正在学习、想从第一天起就养成好习惯的人：先定作用域，再敲命令。带团队、不希望有人对着从聊天里粘贴来的 IP 手敲 `nmap` 的人。

## 不适合谁

想偷偷扫描的人。这里没有 zombie 扫描、诱饵（decoy）、伪造（spoofing）或分片：它们都是被禁标志。Nmap 本身支持这些功能，在授权项目中确实需要的人知道去哪里找。
